# Chrome Web Store Listing

## Name

Stoic YouTube

## Short Description

Remove Shorts and blank the YouTube homepage so you search with intention.

## Detailed Description

Stoic YouTube helps you use YouTube more intentionally.

It removes distracting recommendation surfaces from the YouTube web experience so you can focus on what you actually came to learn or watch.

V1 features:

- Hides YouTube Shorts across the web app.
- Redirects Shorts pages away from `/shorts/...`.
- Blanks the YouTube homepage feed.
- Keeps search, normal video pages, and regular browsing usable.
- Runs locally in your browser.

Stoic YouTube does not collect, store, sell, or transmit personal data.

This extension is not affiliated with YouTube or Google.

## Permission Justification

### Host permission: `https://www.youtube.com/*` and `https://m.youtube.com/*`

Stoic YouTube needs access to YouTube pages so it can detect Shorts links, hide recommendation surfaces, and blank the YouTube homepage feed. The extension does not read pages outside YouTube.
